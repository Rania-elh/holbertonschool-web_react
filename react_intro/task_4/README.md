# Holberton School - React Intro - Task 4

School dashboard built with Vite and React.

This task deploys the application to GitHub Pages.

## Project location

The application is in the `dashboard/` directory.

## Getting started

```bash
cd dashboard
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm test` - Run Jest tests
- `npm run deploy` - Deploy to GitHub Pages

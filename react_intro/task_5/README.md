# Holberton School - React Intro - Task 5

School dashboard built with Vite and React.

This task reorganizes the project structure into App, Notifications, utils, and assets folders.

## Project location

The application is in the `dashboard/` directory.

## Getting started

```bash
cd dashboard
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm test` - Run Jest tests

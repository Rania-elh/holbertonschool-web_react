# React Intro - Holberton School

This project introduces React, a JavaScript library for building user interfaces, through a series of incremental tasks that build a School dashboard application.

## Project structure

Each task is in its own directory and builds on the previous one:

- `task_0/` - Basic application setup with Vite, React, Jest, and the initial App component
- `task_1/` - Basic tests for the App component using React Testing Library
- `task_2/` - Embedding expressions, utility functions, and the Notifications component
- `task_3/` - Login form (email, password, OK button) added to the App component
- `task_4/` - Tests for the login form (inputs, labels, button)
- `task_5/` - Updates to the Notifications component (close button, list, urgent priority)
- `task_6/` - Unit tests for utility functions
- `task_7/` - Unit tests for the Notifications component
- `task_8/` - Deployment to GitHub Pages
- `task_9/` - Reorganization of the project files into folders

## Technologies

- React
- Vite
- Jest + React Testing Library
- ESLint
- gh-pages (for deployment)

## Getting started

Each task contains a `dashboard/` subdirectory with the application code.

```bash
cd task_0/dashboard
npm install
npm run dev
```

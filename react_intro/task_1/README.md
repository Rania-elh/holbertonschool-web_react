# Holberton School - React Intro - Task 1

School dashboard built with Vite and React.

This task adds utility functions (`utils.js`), a Notifications component, and updates the App footer.

## Project location

The application is in the `dashboard/` directory.

## Getting started

```bash
cd dashboard
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm test` - Run Jest tests

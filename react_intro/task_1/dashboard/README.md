# Holberton School - React Intro - Task 1 Dashboard

Basic Holberton School dashboard built with Vite and React.

## Description

This task adds tests for the App component using React Testing Library and Jest:

- Tests the h1 with text "School dashboard"
- Tests the body paragraph with the login text
- Tests the footer paragraph with the copyright text
- Tests the img element with the Holberton logo

## Scripts

```bash
npm install
npm run dev      # Start dev server
npm run build    # Build for production
npm run lint     # Lint the code
npm test         # Run Jest tests
```

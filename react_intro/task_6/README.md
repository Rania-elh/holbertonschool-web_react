# Holberton School - React Intro - Task 6

School dashboard built with Vite and React.

This task adds unit tests for utility functions (`utils.spec.js`).

## Project location

The application is in the `dashboard/` directory.

## Getting started

```bash
cd dashboard
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm test` - Run Jest tests
